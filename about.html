建站历程｜我的专属个人博客

从零开始搭建属于自己的个人博客，全程自主摸索、慢慢打磨，用心打造独属于自己的小世界。

首先在本地整理整体文件结构，使用 HTML 编写网页，制作主页与多个专题页面，分类收纳图文素材，统一管理图片资源。反复调整排版样式与页面跳转链接，在本地不断预览调试，保证文字、图片与各个页面都能正常流畅访问。

最初选择 GitHub 仓库存放文件，但日常访问十分不稳定，经常加载卡顿、无法进入。中途尝试更换其他代码仓库过渡使用，直到夜间网络相对顺畅时，才顺利正常访问 GitHub。随后借助 GitHub Pages 完成线上托管，获取专属访问域名，成功让个人博客正式上线。但长期使用后依旧问题明显：国内访问波动大、加载缓慢，每次修改内容都需要手动上传替换，Git工具与客户端操作复杂繁琐，并不适合日常轻量化更新维护。

为了解决访问难题，我陆续了解并测试过 Gitee、Vercel 等主流托管平台。无奈 Gitee Pages 早已全面下线无法使用，Vercel 也存在网络受限、部署不稳定的问题，综合考量后全部放弃，避开流程复杂、限制较多的部署方案。

斟酌再三，最终还是继续沿用 GitHub 仓库托管。期间也曾尝试安装 Git 工具实现本地同步修改，奈何网络环境不稳定，操作依旧麻烦。最后选择最简单轻便的方式，直接在 GitHub 网页端在线修改、更新内容。不用复杂部署，不用繁琐工具，以最简单的方式收藏热爱、记录生活。慢慢编辑，长久更新，这只属于我的小众小博客，安静又温柔。
